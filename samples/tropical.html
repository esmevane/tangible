sample design tokens by tangible — a JSON spec becomes a sheet of CSS custom properties.

01

Palettes

Raw colour scales emitted from the spec. Each scale is either an explicit hex list or interpolated between stops in oklab, rgb, or lab.

02

Semantic colours

Named roles bound to palette shades. Use these in product code; the raw palettes are implementation detail. Each theme decides its own vocabulary.

03

Contrast

For every semantic colour, tangible picks the higher-contrast ink by WCAG luminance and emits a paired text-shadow.

Surface with paired ink

Body type set on a surface tile uses --color-surface-ink for legibility.

var(--color-surface), var(--color-surface-ink)

Text used as a surface

When the text colour itself becomes a background, the paired ink keeps the contrast intact.

var(--color-text), var(--color-text-ink)
04

Typography

Three families: a display face for headings, a body sans for prose, and a monospace for code and variable names. Sizes, weights, and line-heights are all tokens.

Aa Bb Cc 01

Body type, set at var(--font-size-md) and var(--line-height-md). Held to roughly sixty characters of line length so the eye can track without strain.

use tangible::{Renderer, Spec};

let spec: Spec = serde_json::from_str(json)?;
let css = Renderer::new().render(&spec)?;
05

Space

A short scale used consistently produces rhythm. The bars below render at the actual emitted widths.

--space-sm
--space-md
--space-lg
06

Dimensions

Width tokens for containers and constrained content.

--dimension-sm
--dimension-md
--dimension-lg
07

Borders

Radii and stroke widths, named on the same sm/md/lg scale.

--radius-sm
--radius-md
--radius-lg
--border-width-sm
--border-width-md
--border-width-lg
08

Shadows

Multi-layer drop shadows, named by elevation.

--shadow-neutral-low
--shadow-neutral-medium
--shadow-neutral-high
09

Gradients

Colour-space-interpolated gradients, emitted both as var references and as pre-resolved strings.

10

Glows

Coloured drop shadows, named by intensity.

11

Transitions

A single default timing curve. Hover the button to see it in motion.
